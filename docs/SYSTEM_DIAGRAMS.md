# Диаграммы системы Hephaestus

## 1. Общий поток данных (Data Flow)

```
┌──────────────────────────────────────────────────────────────────────────┐
│                            HEPHAESTUS СИСТЕМА                            │
└──────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────┐
    │  HeadHunter API │
    │  (вакансии)     │
    └────────┬────────┘
             │
             ▼
    ┌─────────────────────────────┐
    │  1️⃣ СБОР ВАКАНСИЙ           │
    │  Загружаем с HeadHunter    │
    │  Сохраняем в PostgreSQL    │
    └────────┬────────────────────┘
             │
             ▼
    ┌─────────────────────────────────────────────┐
    │  2️⃣ ИЗВЛЕЧЕНИЕ НАВЫКОВ (AI)                │
    │  Система читает описание вакансии           │
    │  Подчёркивает требуемые навыки             │
    │  Создаёт список: "Требует проверки"        │

             │
             ▼
    ┌───────────────────────────────────────────────────┐
    │  3️⃣ ОЧЕРЕДЬ НА МОДЕРАЦИЮ (Skills On Review)      │
    │  Навыки ожидают вашей проверки                  │
    │  "React?" - "Да, это React"                     │
    │  "JS?" - "Это синоним JavaScript"               │

             │
             ▼ (Вы одобряете)

    │  4️⃣ СПРАВОЧНИК (Clean Skills)              │

    │  "React" с синонимами: react.js, React.js  │
    │  "JavaScript" с синонимами: JS, js          │
    └────────┬────────────────────────────────────┘
             │
             ▼
    ┌─────────────────────────────────────────────┐
    │  5️⃣ ОРГАНИЗАЦИЯ                            │
    │  Связи между навыками                      │
    │  Распределение по профессиям               │
    │  Определение уровней (Junior/Middle/Senior)│
    └────────┬────────────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────────────┐
    │  6️⃣ АНАЛИТИКА И РЕКОМЕНДАЦИИ               │
    │  Карьерные траектории                       │
    │  Что требуют в вакансиях?                   │
    │  Как развиваться?                           │
    └──────────────────────────────────────────────┘
```

## 5. Процесс нормализации (пример)

```
Входные данные (из вакансий):
├─ "React"
├─ "react.js"
├─ "React.js"
├─ "REACT"
├─ "Реакт"
├─ "react JS"
└─ "React Framework"

                ⬇ Нормализация

Шаг 1: Привести к нижнему регистру
├─ "react"
├─ "react.js"
├─ "react.js"
├─ "react"
├─ "реакт"
├─ "react js"
└─ "react framework"

                ⬇

Шаг 2: Убрать точки и пробелы
├─ "react"
├─ "reactjs"
├─ "reactjs"
├─ "react"
├─ "реакт"
├─ "reactjs"
└─ "reactframework"

                ⬇

Шаг 3: Проверить в справочнике
├─ "react" → найдено: React ✅
├─ "reactjs" → похоже на react → синоним ✅
├─ "reactjs" → похоже на react → синоним ✅
├─ "react" → найдено: React ✅
├─ "реакт" → семантически React → синоним ✅
├─ "reactjs" → похоже на react → синоним ✅
└─ "reactframework" → не совпадает → новый? ⚠️ требует проверки

                ⬇

Результат:
✅ React
   ├─ Синонимы обнаружены: react.js, react, Реакт, react js
   ├─ Все варианты указывают на один навык
   └─ Счётчик: 7 вакансий требуют этот навык
```

## 7. Граф связей навыков

```
                    [JavaScript]
                     /    |    \
                    /     |     \
                   /      |      \
                [React] [Node.js] [Vue]
                /   \       |        \
               /     \      |         \
           [Redux] [TypeScript] [Express]
             |       /   \         |
             |      /     \        |
             |  [Jest]  [HTML]   [MongoDB]
             |              \      /
             |               \    /
             └──── [CSS] ─────┘ ─┘

Сплошная линия = часто требуются вместе (>80%)
Пунктир = иногда требуются (50-80%)
Отсутствие связи = редко требуются (< 20%)
```

## 8. Процесс принятия решения модератором

```
Вы видите: "React.js"

                ⬇

Вопрос 1: Это правильно извлечено?
    [✓ Да] → [✗ Нет] → Отклонить
       ↓                    ↓
   Вопрос 2         [Удалено из БД]
       ↓
Вопрос 2: Это новый навык или синоним?
    [Новый] → [Синоним]
       ↓          ↓
   Вопрос 3   Выбрать существующий
       ↓       ("React" из справочника)
   Вопрос 3        ↓
       ↓      [Связано: React.js → React]
Заполнить:
   • Отображаемое имя
   • Тип (фреймворк)
   • Направление (Frontend)
   • Профессия (Frontend Dev)
       ↓
   [Одобрить]
       ↓
[Добавлено в справочник ✅]
```
